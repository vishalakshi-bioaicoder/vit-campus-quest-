# VIT Campus Quest

## Overview
VIT Campus Quest is a Python-based interactive command-line adventure game. Players can explore various campus locations, complete Python coding challenges, and earn points to achieve different campus ranks. This project is submitted for the Python Essentials evaluated course project.

## Features
* **Interactive Menu:** Easy-to-use command-line interface.
* **Campus Locations:** Explore the Academic Block, Library, and Innovation Lab.
* **Coding Challenges:** Solve module-specific Python questions to earn points.
* **Scoring System:** Dynamic ranking based on the total score (e.g., Campus Champion, Excellent Explorer).

## Technologies Used
* Python 3.x

## How to Setup and Run
1. Download or clone this repository to your computer.
2. Open your terminal or command prompt.
3. Navigate to the project folder.
4. Run the game using the following command:
   `python main.py`

## Testing Instructions
The project includes basic assertion tests for scoring, ranking, and location tracking. 
Run the individual modules (like `player.py` or `scoring.py`) to see the "PASSED" test messages.
