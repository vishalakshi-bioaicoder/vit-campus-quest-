# Problem Statement
The goal of this project is to create an interactive command-line adventure game for VIT Bhopal students that tests their Python skills through engaging campus-themed challenges.

# Scope
The game covers three primary locations: Academic Block, Library, and Innovation Lab. It includes a scoring mechanism, location tracking, and an evaluation system based on the points earned.

# Target Users
First-semester engineering students, coding beginners, and Python enthusiasts.

# High-level Features
* Interactive text-based navigation system.
* Location-based Python trivia and challenges.
* Real-time score calculation and tracking.
* Final ranking generation based on user performance.
